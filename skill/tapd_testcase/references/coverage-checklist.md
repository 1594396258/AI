# Coverage Checklist

Use this checklist before writing the workbook.

- Requirement sections and page/dialog hierarchy
- Filter fields, default values, ranges, query behavior
- Table columns, display rules, sorting, pagination
- Buttons and operation availability by status
- Form fields, dynamic show/hide rules, required validations
- Enum values and unsupported values
- Task lifecycle and state transitions
- Manual retry/regeneration, idempotency, overwrite rules
- Scheduled daily/monthly execution rules
- File name, sheet name, row layout, summary fields, detail fields
- Amount formulas, rounding, sign rules, exchange-rate rules
- Time zone rules and date-cut rules
- Permission matrix, front-end hiding, back-end interception
- Data isolation by institution/merchant/channel
- Empty-data behavior
- Failure handling and alert content
